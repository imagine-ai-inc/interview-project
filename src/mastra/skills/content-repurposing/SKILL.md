# Skill: Long-Form Content Repurposing

How to convert a rough draft or notes file from the workspace into multi-channel posts:
1. Identify the single biggest contrarian insight.
2. Draft a 120-word executive LinkedIn post with a scroll-stopping hook.
3. Extract 3-4 tactical bullet points for an X thread.
4. Call `create_post` to store the draft in SQLite.
